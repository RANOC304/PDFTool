# Contributing to Massicot

Open an issue with the tool or conversion route, browser and operating system, and steps to reproduce the problem. Use a synthetic sample if the behavior depends on an input file. Include the expected output and what you observed.

For a pull request, use the [local setup](README.md#development). Run the build and the audits relevant to your change, then describe what you verified. Keep generated conversion outputs and browser profiles out of commits.
